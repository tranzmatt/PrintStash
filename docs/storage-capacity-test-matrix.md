# Storage capacity test matrix

Requirements: identity-based owned-byte accounting, distinct logical/external/lifecycle categories,
serialized peak admission on the actual filesystem, conservative unknown evidence, durable recovery,
bounded dated history, access-controlled drilldown, explicit receipt-verified cleanup, and usable Settings feedback.

The focused owner run covers these behaviors. Aggregate backend/frontend coverage gates are run by the integration owner; no coverage floors were lowered. Existing backup/media compatibility coverage also passed (255 tests).
